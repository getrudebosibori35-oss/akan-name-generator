# Akan Name Generator

A simple web app that calculates and displays an Akan name based on a user’s birthday and gender.

## Features
- Enter your day, month, and year of birth
- Select your gender
- Click the generate button to see your Akan name
- Displays the result on the page instantly

## Files
- index.html — the structure of the webpage
- style.css — styling for the form and result display
- script.js — the logic that generates the Akan name

## How to Use
1. Open index.html in your browser.
2. Fill in your birth details.
3. Choose your gender.
4. Click the Generate My Akan Name button.

## Example
After entering your birthday and selecting your gender, the app will display a message like:

Your Akan name is Kwasi

## Notes
This project is built with plain HTML, CSS, and JavaScript.
